Privacy and limits
Zero egress. Your character, motion and exported GLB never leave this device. Open DevTools, Network tab, and run a bake: only static files from this site are requested, and none after the first load once the service worker has cached them. The one exception is the optional Try with the sample button, which downloads the X Bot character from jsDelivr (a read-only GET; nothing is sent) and is cached afterwards. This is a pure transform: it has no git, token, upload or versioning, and inputs given as ?character=&motion= URLs are fetched with a read-only GET.
  • No foot-lock or IK yet: very short or long legged targets can slide.
  • Swing-only alignment fixes direction, not roll: differing rest roll can twist forearms.
  • FBX is the least predictable input (twin bones, units, external textures); GLB is cleaner.
  • Large textured characters are texture-bound on export; use --max-tex on phones.
  • Tested on Mixamo and synthetic A-pose / Blender-axis rigs. Real Blender, VRM, Ready Player Me, twist bones and non-humanoids are still untested.
